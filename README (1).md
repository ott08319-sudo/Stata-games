# Игровой Telegram-бот

Аналог видимой части интерфейса по скриншоту. Использует только
виртуальную валюту: платежей и вывода денег нет.

## Запуск

Нужен Python 3.11+.

1. Поместите все файлы проекта в одну папку (`/app` или папку проекта).
2. Убедитесь, что в именах файлов нет суффиксов `(1)` или `(2)`.
3. Установите зависимости:

   pip install -r requirements.txt

4. Переименуйте `env.example.txt` в `.env` (или задайте переменные окружения в панели хостинга) и укажите `BOT_TOKEN`.
5. Запустите:

   python main.py

## Переменные окружения

- `BOT_TOKEN` — обязателен; токен Telegram-бота от `@BotFather`.
- `DB_PATH` — необязателен; путь к SQLite, по умолчанию `game.sqlite3`.
- `NEWS_URL` — необязателен; ссылка для кнопки `📣 News` в меню игр.
- `CHAT_URL` — необязателен; ссылка для кнопки `💬 Chat` в меню игр.
