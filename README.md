# Игровой Telegram-бот (aiogram 3 + SQLite)

Аналог видимой части интерфейса по предоставленному скриншоту.
Работает исключительно на виртуальной внутренней валюте (платежи и вывод средств отсутствуют).

## Структура проекта

- `main.py` — точка входа, загрузка `.env`, инициализация БД и запуск polling
- `database.py` — потокобезопасная работа с SQLite (пользователи, баланс, раунды, автовозврат незавершённых ставок)
- `handlers.py` — команды (`/start`, `/play`, `/balance`, `/menu`, `/cancel`), навигация по меню, FSM ставок и игровая логика
- `keyboards.py` — reply- и inline-клавиатуры главного меню, игр и быстрых ставок
- `middlewares.py` — логирование исключений и безопасный ответ пользователю при сбое
- `requirements.txt` — зависимости Python
- `env.example` — шаблон переменных окружения (переименуйте в `.env`)

## Запуск

Требуется **Python 3.11+**.

1. Поместите все файлы проекта в одну директорию.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Переименуйте `env.example` в `.env` и укажите ваш `BOT_TOKEN` от `@BotFather`.
4. Запустите бота:
   ```bash
   python main.py
   ```

## Переменные окружения

| Переменная | Обязательна | Описание |
|---|---|---|
| `BOT_TOKEN` | Да | Токен Telegram-бота от `@BotFather` |
| `DB_PATH` | Нет | Путь к файлу SQLite (по умолчанию `game.sqlite3`) |
| `NEWS_URL` | Нет | Ссылка для кнопки `📣 News` в меню игр (`https://...`) |
| `CHAT_URL` | Нет | Ссылка для кнопки `💬 Chat` в меню игр (`https://...`) |

## Примечания по реализации (`NOT OBSERVED`)

На скриншоте наблюдались только главное меню, reply-клавиатура и экран выбора игр.
Внутренние `callback_data`, точные формулы коэффициентов, стоимость VIP-статуса, размер реферальной награды и ежедневного бонуса спроектированы для работоспособности прототипа и помечены комментарием `NOT OBSERVED` в исходном коде.
